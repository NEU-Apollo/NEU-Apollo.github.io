同时重定向标准输出和标准错误输出

2025-09-27

在 Shell（如 Bash）中，&> 和 |& 是用于重定向标准输出（stdout）和标准错误（stderr）的语法糖。它们的作用如下：

1. &>：同时重定向 stdout 和 stderr 到文件

等价于：

  • 将命令的 标准输出 和 标准错误 都写入 file。
  • 如果文件已存在，会被覆盖；若要追加，应使用 &>>（Bash 4.0+）。

示例：

无论 ls 成功还是报错，所有输出都会写入 output.log。

2. |&：将 stdout 和 stderr 一起通过管道传递给下一个命令

等价于：

  • 把 command1 的 stdout 和 stderr 合并，作为 command2 的输入。

示例：

即使 grep 报错（如文件不存在），错误信息也会被 tee 捕获并写入文件。

注意事项：

  • &> 和 |& 是 Bash 特有 的扩展语法，在 POSIX shell（如 sh）中不可用。
  • 在脚本中追求可移植性时，建议使用标准写法：> file 2>&1 或 2>&1 | ...。
  • 在 Zsh 中，&> 同样有效，但 |& 的行为可能略有不同（不过通常兼容）。

总结对比：

语法 含义 等价写法
&> file stdout + stderr → file > file 2>&1
|& cmd stdout + stderr → 管道 → cmd `2>&1
